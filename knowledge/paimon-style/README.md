# 派蒙风格素材

这是一份可审阅的表达素材集，不是新增剧情知识集合。原始资料仍在 `../characters/`，运行时不会检索本目录或把内容当作用户记忆。

- `corpus.json`：恢复男女旅行者共用引用后，按原条目标识精确去重的 178 条对话。保留原文、逐行说话者、合并的发言和各自来源；男女差异不按相似语义强行合并。来源快照摘要（统一 LF 换行后的 SHA-256）和观测枢语音页链接记录在 inputs。
- `curation.json`：开发助手逐条核对的 32 组素材及学习要点、限制，其中 6 组带固定节选范围。不是用户盲评认可，也不证明模型已学会这些习惯。excerpt 为原始 lines 的零基半开区间；保留前后完整原文供核对。
- `eval-cases.js`：60 个独立编写的合成场景，含 5 组两轮对话，不来自私人聊天，不进入运行时提示。
- `../../lib/paimon-style-data.js`：由审阅清单生成的六组短示例，代码更新时随 Git 分发，不需要服务器重建知识索引。

```sh
node scripts/paimon-style.js check
node scripts/paimon-style.js build
```

在插件根目录执行。check 检查来源摘要、旅行者引用、说话者、节选范围及生成内容是否一致。原文变动导致审阅条目标识消失时，build 会拒绝继续，需重新核对并更新清单。新语音只进入候选集，不自动成为风格示例。不要手改生成的 corpus 或 JS。

取材原则：只参考派蒙的回应方式，旅行者发言提供语境；不复制旅行者的冷幽默给派蒙。强烈依赖铺垫的长段落、占卜猜测、夸张幻想、索要财物等保留研究注记，不作为通用行为规范。原文中有些关心以玩笑收尾，节选只取需要的局部；完整上下文仍可核对，不能将局部分析理解为整段的唯一含义。

运行方式、评测及限制见 [实施文档](../../docs/PAIMON_STYLE.md)。
