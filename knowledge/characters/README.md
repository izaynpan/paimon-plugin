# 中文角色资料采集

2026-10-27：以观测枢丝柯克（词条 505417）作为首个样本。只采集用户选定的七类中文文本：基础档案、角色介绍、角色故事、语音台词、人物关联、生日邮件、特殊料理。

每个角色输出 `词条编号.zh-CN.md`（阅读）和 `词条编号.zh-CN.json`（结构化数据）。这里只保存采集资料，尚未加入 `knowledge/sources.json` 或构建活动检索索引。

## 复用命令

在插件根目录运行（Node.js 18+，无需登录、Cookie、模型 API 或额外依赖）：

```sh
node scripts/collect-character.js 505417
node scripts/collect-character.js "https://baike.mihoyo.com/ys/obc/content/505417/detail"
```

默认输出至本目录；再次运行会更新同 ID 的两份文件，完成后查看 Git 差异。可用 `--out <目录>` 写入另一个目录进行比较。

已有公开接口原始 JSON 时可离线转换：

```sh
node scripts/collect-character.js 505417 --input <原始响应.json>
```

离线转换以输入文件修改时间作为抓取时间的代理；输入应是刚抓取且未改写的快照。丝柯克首份资料来自本会话已下载的临时快照，文件修改时间为北京时间 2026-10-27 01:00:01。来源元数据包含页面版本和输入文件 SHA-256 摘要；网页版本不是已核实的游戏版本。

## 获取与清洗规则

1. 从角色页取得数字 ID，以公开只读接口 `/hoyowiki/genshin/wapi/entry_page` 查询 `entry_page_id`、`lang=zh-cn`。接口主机为 `act-api-takumi-static.mihoyo.com`，系本次从网站脚本核对的地址，并非承诺稳定的开发者 API。
2. 校验返回码、词条 ID、模块类型；失败或关键结构变化时停止，不猜测正文。请求超时 20 秒，不自动重试。
3. 基础信息取字段白名单；角色介绍取“更多描述”“角色详细”；故事通过页面“角色描述”分组识别，保留特殊故事原题，排除已单独整理的介绍、邮件、料理和空模块。
4. 语音只取汉语／中文标签中的标题与正文。所有音频地址、图片地址、外语标签、CV、攻略和技能数据均不进入输出。普通文本中的原始用词不自动翻译或改写。
5. 关联角色只取“相关角色”子栏目；本人“关于…”评价引用语音标题，不复制正文，其中可能包含概念而非人物。关系网中的他人评价保留说话者和原文。不根据链接或共现自动推断师徒、亲属等关系。
6. 邮件、料理只收录本页正文。图片和链接标记去除，可见文字、段落保留；不递归读取外链，不补写缺失料理说明或历年邮件。
7. JSON 和 Markdown 保留来源与采集说明。缺少可选内容时明确记录，不能把“本页没有”理解为“角色不存在该资料”。
