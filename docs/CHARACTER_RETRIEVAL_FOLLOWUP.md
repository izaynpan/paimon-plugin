# 角色台词跨页检索与出处追问修正

2026-10-30。范围：本地检索及共用资料提示，不改变联网额度、会话触发或资料原文。

## 问题与方案

角色资料已入库，但按人物文件筛选会漏掉其他人的台词中谈及该人物的内容。单字姓名的保护条件和有限的代词续话规则，也会漏掉用户补充说话者的自然表达。

1. 档案、生日、料理、邮件及有方向的人物评价继续使用原有约束。对台词、笑话、原句和故事内容，增加跨角色资料候选：正文须提及已识别人物，并匹配去掉人物名和提问套话后的有效内容词。保留原资料所属人物、说话者和出处，不能把被谈论者当成说话者。
2. 单字姓名增加明确说话句式识别，继续拒绝“荧光”“空气”“练琴”等普通词。明确出处追问只结合最近同一用户的相关问题或显式引用；不继承其他人的话题，不跨越换话题提示，不猜多人物歧义。
3. “旅行者语音”与另一个角色同时出现时，仍查询旅行者共用台词，不因识别出另一个人物而丢掉旅行者。
4. 共用提示区分“邀请听一个新笑话”和“核对已有角色台词”。用户提示出处而现有证据不足，且本轮允许补查时，先补查一次；资料足够则直接回应。不新增模型调用上限，不把漏检说成从未发生。

## 验证与交付

使用公开角色资料及合成问句验证跨页内容、说话者追问、同作者隔离、换话题、引用、歧义、普通词、旅行者共用资料和关闭角色集合；不复制私人日志或用户身份到测试。运行原角色 126 题、剧情回归及插件离线测试。此次仅修改本地代码并提交，线上生效需后续更新代码和重启；原快照无需重建。

## 无独立档案人物与连续追问补充

同日补充修正：芭比洛斯未在人物登记表中，但法尔伽语音和故事、杜林故事已明确提及她。此前按人物档案筛选会直接跳过这些证据。

- 从现有语音的“关于……”标题获取精确检索词；对“关于某人的资料”“某人的故事”等明确问句，提取 3～18 字的字面检索词。只查原文明确出现该词的片段，不自动新增人物身份、别名或亲属关系。没有独立档案的已登记人物也可查跨页提及。
- 广泛询问资料时，在两类集合都有候选且预算允许的前提下，为角色资料与剧情资料各保留至少一段。保留原说话者和资料所属人物，不将被提及的人当作该档案的主人。
- “有没有更多线索”“能再讲一点细节吗”等续话沿用最近同作者的明确主题；在最近三批、最多四条同作者消息内，只跨过明确的简短追问或感想。新话题、不明确的中间消息、多主题歧义或多人批次阻止自动衔接，显式引用优先。
- 生日、料理等字段仍受原有约束；字面检索没有未知名字的自动拼音纠错或任意语义改写能力。标题/问句提取可能漏掉未覆盖表达，不能据此声称人物不存在。
- 仅加载时准备附加检索信息，原快照兼容；不修改资料原文、登记表或模型调用次数。更新代码并重启即可，仍未推送或部署。
