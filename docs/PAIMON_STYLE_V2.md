# 派蒙风格第二轮对照

2026-11-11 设计并运行，2026-11-12 整理。目的：分别评估角色感与回答是否合适，检查增加候选、按场景选例和多轮互动的效果。属于离线实验，线上仍仅支持原来的 off/rules/examples，默认 off；未修改生产提示或服务器。

## 对照设计

| 实验方案 | 规则 | 示例 |
| --- | --- | --- |
| off | 原人设 | 无 |
| rules | 原人设 + 接话规则 | 无 |
| examples | 同上 | 原有固定 6 组 |
| fixed2 | 同上 | 固定 2 组，作为示例数量对照 |
| adaptive2 | 同上 | 从 24 组候选中选 0～2 组 |

新增 24 个合成场景，16 个单轮、8 个三轮，共 40 个待回复节点；每种方案重复 5 次，合计 1,000 次请求。与上一轮 60 题不同，覆盖调侃转认真、夸奖后收敛、想象与事实边界、停止笑话、允许独处、群聊停止再唤起等。没有扩大到更多独立场景：本轮增加的是重复次数和连续对话，因此不能称为全面扩大领域覆盖。

沿用同一个 deepseek-flash、temperature=0.8、maxTokens=600、关闭思考、不重试、3 路并发。每个方案的后续轮次继承自己的回复，不串用其他方案的历史；这些轮次不是独立样本。任务顺序随机，盲评的字母顺序每个场景/重复独立打乱，同段对话内保持一致。

候选扩充：在已审阅的 32 组原文中重新核对 24 组短节选，保存到 `knowledge/paimon-style/experiment-curation.json`，含原条目标识、范围、说话者、学习要点与禁用情境。生成的 `experiment-pool.js` 只由评测脚本加载，不进入线上聊天。原来固定 6 组保持不变。

动态选择是保守的本地词面规则实验，尚非语义分类器：只看当前用户文本，不读取测试类别或标准答案；明确停止、认真、难过、事实核查等情况不给示例；未知场景也允许空选。多作者批次空选；最近两轮已用示例尽量避开；最多 2 组，示例 JSON 不超过 850 码点。fixed2 控制示例数量，但未严格控制 token、内容、片段长度；adaptive2 弃选时实际退回 rules，所以不能将整体差异全部归因于检索质量。不能把这次实验描述为模型训练或微调。

## 如何评阅

生成的 `review.html` 是可直接双击打开的独立页面，无外部依赖、无上传行为。默认提供预先选定的 12 组入门对照，也可切换全部 200 组（1,000 条回答）；多轮节点可展开各自真实前文。默认选择规则在请求之前确定，不按回答好坏挑选展示样本。

评分分两列，不合并成总分：

- **角色感 1～5**：很不像、偶有一点、有些像、比较像、很自然地像。看接话方式、反应、伙伴感，不只统计语气词。
- **合适程度 1～5**：明显不合适、问题较多、基本可用、合适、很贴切。看是否理解当下意思、尊重要求、没有无依据编造。

允许留空、并列；要求安静时沉默可以合适，角色感可不评分。另可勾选虚构经历、没接住意思、重复口癖、不尊重停止、过长等问题，写简短感受。评分保存于浏览器本地，导出带运行标识的 JSON 后才能由脚本汇总；我无法从页面自动收到用户评分。

HTML 只嵌入问题、匿名回答及前文，不带模式、示例选择或解盲映射。每次生成有独立 runId，防止相同实验重复运行、字母重新随机后误用旧评分。实验指纹另用于追踪配置和候选版本；导入评分同时验证 runId 与指纹。测试页面和实际盲评使用不同运行标识，测试评分不进入正式评测。

## 命令与产物

在插件根目录运行：

```sh
node scripts/paimon-style.js check
node scripts/eval-paimon-style.js prepare --study=v2 --repeats=5
# 真实请求，从环境变量 DEEPSEEK_API_KEY 读取；单次最多 1,200 次请求
node scripts/eval-paimon-style.js run --study=v2 --repeats=5
# 用户评分后，将其与生成该页面的同一次评测关联
node scripts/score-paimon-style.js data/paimon-style-eval/<运行目录> <导出的评分.json>
```

每次使用新目录，不覆盖原结果。保留 manifest、每一轮实际请求、选例元数据、完整响应及 usage、blind-review、独立 blind-key、review.html 和摘要。个人配置与 key 不进入请求存档，样例也不来自私人 QQ 聊天。输出目录继续被 Git 忽略。

评分汇总对两个维度分别计算；先在同一场景内部平均，再按场景等权，避免多轮/重复较多的场景压倒其他场景。配对比较只用同一场景、重复、轮次都已评分的两条回答，并给出配对数量与独立场景数。未配对评分、少量用户评分或选择性样本不能推出总体显著性；没有输出伪造的置信区间或提升百分比。
