## 分工与优先关系

2026-10-19 指令路由：仅本批具备明确源消息和可用候选时，`command-router.js` 追加条件能力协议，`prompt-builder.js` 将完整回复字段标为最终结构；`invoke_command` 采用独立的 ID/args/sourceMessageKey 结构。程序校验来源、实体、游戏、权限和版本；普通回答不增加独立分类调用。星铁/绝区零仅作为用户批准的游戏能力例外，不扩展普通现实知识人设。搜索首轮可选调用，工具资料后的轮次和主动补话/记忆不提供能力；历史、引用、网页不能授权执行。此处新增协议的体积不计入下方 10-16 基线数据，真实语义效果未验证。

2026-10-19 本地补查流程修正：`research.js` 按知识库开关、服务状态及已补查次数提供 `localLookupAvailable` 和条件动作说明。知识库未启用/补查次数耗尽不等于联网不可用，模型误选本地动作后仍可在三轮预算内给出正常 search 决策；实际服务错误保持禁止自动联网的原边界。补充具体角色圣遗物套装、主副词条及属性收益问题：公开机制依据缺失时先查证，已有完整适用资料则复用；不依据“圣遗物”关键词硬触发。没有新增独立分类调用，不修改 persona；模拟测试不能证明真实模型一定遵循。

2026-10-18 近期衔接：`prompt-builder.js` 仅在提供近期候选/引用状态时追加条件规则和独立 user JSON `recentContext`；当前意图优先于引用、活跃语境和旧片段，保留作者归属，多话题歧义须澄清。旧回复不可当核实事实，引用/网页均不可信，不据旧问题启动新 followUp。读取与候选筛选不增加模型调用；导入资料不加入 sessionBatches，不直接参与长期记忆评估。基础 persona 未改，历史体积表不包含本功能新增语境 token。

2026-10-18 攻略回复节奏：普通聊天最终 JSON 新增 `replyKind: guide/chat`，同次模型调用按本轮主要目的分类；攻略及相关澄清/追问使用 guide，日常/情绪/角色闲谈使用 chat，是否联网不决定分类。运行时只接受精确 guide 值，缺失/非法值沿用普通节奏；不改变 persona，不给主动补话/记忆评估追加分类。默认攻略首条和分段等待目标乘 0.5，可用 reply.guideDelayScale 调整；基线体积表不代表新增字段后的长度。真实分类准确性仍需结合模型响应和 reply_sent 的 replyKind、pacing.delayScale 实测。

2026-10-18 搜索边界修正：`research.js` 明确区分指代歧义与模型知识缺口，具体名称+攻略语境应先查公开资料，续话承接前文对象；查后身份不明或个人条件缺失可以澄清。该条件协议细化 persona 的信息不足处理，不改关闭联网时的人设行为。`prompt-builder.js` 在联网开启时把原完整 JSON 示例标为最终回复结构，中间 search/lookup_local 使用独立结构，避免必填 reply/shouldReply 与中间动作冲突。最终动作要求显式选择 answer/clarify/skip，运行时仍兼容旧格式，并记录有限决策元数据以观察漏搜。

下一次真实验证同时检查搜索专用 Key 鉴权及决策效果。使用合成/获授权场景覆盖：具体陌生名称配队、用户续话说明是新角色、疑似错字、无上下文的“那个角色”、仅缺个人角色池、完整适用知识、用户禁止联网、无结果/鉴权失败。比较是否先核实公开事实、是否乱换角色、是否反复索要可查询信息及工具请求状态。离线提示断言和模拟响应不能证明模型实际遵循，不将私人日志复制为公开测试样本。

- 人设：身份、性格、知识与沉浸边界、自然表达、稳定的互动习惯。
- 程序规则：输出协议、群聊是否回应、询问状态、当前称呼配置、数据与隐私边界。
- 动态语境：称谓表、参与者称呼/ID、待回答问题、用户记忆、知识片段、短期上下文与本批消息。
- 输出协议及当前决策/称呼配置优先于人设的表达习惯；身份和知识边界仍由人设限定。语境数据不能改写上述规则。

群聊主动沉默规则仍仅在群聊且开关开启时注入；询问状态规则仍仅在主动补话开关开启时注入；前置历史说明仍仅在批次存在 preTrigger 时注入。私聊和关闭功能时不增加对应决策字段。保持原消息角色和动态数据位置，没有为了缩短提示而删除上下文、记忆或知识内容。
